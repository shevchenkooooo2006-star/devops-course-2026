# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
- Объём оперативной памяти: 2048 МБ
- Количество ядер процессора: 2
- Объём дискового накопителя: 25 ГБ (динамически расширяемый)

## 2. Сетевые интерфейсы
- **Адаптер 1 (NAT)**: полученный адрес 10.0.2.15/24. Назначение: доступ в Интернет (для обновления пакетов).
- **Адаптер 2 (Host-only)**: полученный адрес 192.168.56.102/24. Назначение: доступ с хостовой системы к серверу (SSH, веб-сервер).

## 3. Правило проброса портов
- Порт хостовой системы: 2222
- Порт гостевой системы: 2222

## 4. Учётные записи
- **student**: входит в группу `sudo`. Аутентификация по паролю.
- **devops**: входит в группу `sudo`. Аутентификация по ключу SSH (ed25519).

## 5. Служба SSH
- Порт: 2222
- Изменённые директивы (файл `/etc/ssh/sshd_config.d/99-hardening.conf`):
  - `Port 2222`
  - `PermitRootLogin no`
  - `PasswordAuthentication no`
  - `PubkeyAuthentication yes`
  - `MaxAuthTries 3`
  - `AllowUsers devops`

## 6. Правила межсетевого экрана (UFW)
- Политика по умолчанию: `deny incoming`, `allow outgoing`.
- Разрешённые порты: `2222/tcp` (с ограничением частоты LIMIT), `80/tcp`, `443/tcp`.
